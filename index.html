Privacy and troubleshooting

Your script is processed by the browser's speech engine, not submitted to a narration API. External code and model files are downloaded from third-party content networks. Your script is also saved in this browser's local storage so it survives a refresh; use “Clear script” if you do not want it saved. If model loading fails, check your connection and try Chrome on a laptop or desktop. Do not switch tabs or lock the screen during long recordings. The site must be opened through an HTTPS website, such as GitHub Pages, not directly as a file from your Downloads folder.
